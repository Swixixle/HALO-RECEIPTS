## B) `server/routes.ts` — add Saved Views endpoints

Add these **private** endpoints (require the same `x-api-key` auth middleware as other private routes):

### 1) GET `/api/saved-views`

Returns:

```json
{ "items": [ ...views... ] }
```

Sort order:

* `updatedAt desc`
* tie-breaker `name asc`

### 2) POST `/api/saved-views`

Request body:

```json
{ "name": "...", "description": "...", "filters": { ... } }
```

Strict validation:

* `name`: required, trimmed, 1–64 chars
* `description`: optional, trimmed, max 200
* `filters`: required object
* Reject unknown filter keys (400)
* `q`: trimmed, empty → null, max 128
* `pageSize`: must be 50/100/200
* `status`: enum or null
* `hasForensics/killSwitch`: boolean or null

On duplicate name:

* `409 { "error": "NAME_EXISTS" }`

On success:

* `201` returning created view object

### 3) PATCH `/api/saved-views/:id`

Allows partial update of:

* `name`
* `description`
* `filters` (full object replacement; v1 keeps it simple)

Same validation rules.
Duplicate name → 409 `NAME_EXISTS`.

Not found → 404.

### 4) DELETE `/api/saved-views/:id`

Success → 204.
Not found → 404.
