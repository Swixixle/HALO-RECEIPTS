P0 Required Changes (must do before we call it “forensic-grade”)

P0.1 Separate “Verification” vs “Forensics” explicitly in UI + API

Right now you’re putting forensics into Facts. That can confuse users into thinking heuristics are facts.

Requirement
	•	Facts tab must include two clearly labeled blocks:
	•	FACTS (Verifiable / Directly Observed): computed hash, expected hash, match boolean, canonical transcript string, signature status, failure modes.
	•	FORENSICS (Heuristic / Deterministic Signals): detectors output.

And the UI must stamp forensics with:

“Heuristic signals. Not proof of content correctness.”

P0.2 Add a “Forensics Independence” rule

Forensics must run even when integrity fails — correct — but must never claim “the transcript is X” in a way that implies authenticity.

Requirement
	•	Any forensics output must include:
	•	based_on: "submitted_payload" (not “verified transcript”) if UNVERIFIED
	•	integrity_context: "VERIFIED" | "UNVERIFIED"

So later, nobody can argue you treated tampered content as authentic.

P0.3 PII detector must be strictly non-exfiltrating

You said “never exposes raw values.” Enforce it at type level.

Requirement
	•	Detectors return counts only and optionally redacted shapes, never substrings.
	•	Add a unit test: ensure no output contains @ when email-like detected, or digits sequences that look like phone/SSN, etc.

P0.4 Risk markers: rename + scope

Calling them “risk markers” is fine, but don’t imply classification.

Requirement

Rename in UI to:
	•	“Risk Keywords (Heuristic)”
And ensure you only display:
	•	category flag + match count + confidence level (LOW/MED/HIGH)
No “this is medical advice” statements.

P0.5 High-entropy detection must be defined and bounded

“High entropy blocks” is easy to get wrong and produce noise.

Requirement
	•	Document thresholds in code comments and output:
	•	entropy_threshold
	•	min_block_length
	•	method: “Shannon entropy on sliding window” (or your chosen method)
	•	Add tests for:
	•	base64-like string triggers
	•	normal English does not trigger
