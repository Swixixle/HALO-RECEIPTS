## Replit Agent Instructions — Fix E2E missing `x-api-key` header (P9-4)

### Objective

E2E fails because the **default query fetcher** does **not** send `x-api-key` to **private endpoints** (e.g. `GET /api/receipts`).
Implement a **single source-of-truth fetcher** that injects `x-api-key` **ONLY in dev/test/e2e**, never in production builds. Update the QueryClient/defaultQueryFn to use it. Add `.env` guidance.

---

### Step 1 — Create a central fetch utility

**Create file:** `src/lib/apiFetch.ts`

**Implement:**

* Wrapper around `fetch`
* Adds header `x-api-key` **only if**

  * environment is dev/test/e2e, and
  * URL is **private** (`/api/**` but NOT `/api/public/**`), and
  * header not already present, and
  * env var exists (do not crash if missing)

**Code to use:**

```ts
// src/lib/apiFetch.ts
export async function apiFetch(input: RequestInfo, init: RequestInit = {}) {
  const headers = new Headers(init.headers || {});

  const env = (import.meta as any).env || {};
  const mode = env.MODE;
  const isDevLike = Boolean(env.DEV) || mode === "test" || mode === "e2e";

  const url = typeof input === "string" ? input : input.toString();
  const isPrivateApi = url.startsWith("/api/") && !url.startsWith("/api/public/");

  if (isDevLike && isPrivateApi) {
    const devKey = env.VITE_DEV_API_KEY;
    if (devKey && !headers.has("x-api-key")) {
      headers.set("x-api-key", devKey);
    }
  }

  return fetch(input, { ...init, headers });
}
```

### Step 2 — Update the default Query fetcher to use `apiFetch`

Find where the app defines the **defaultQueryFn** or where queries call `fetch` directly.
Common locations:

* `src/lib/queryClient.ts`
* `src/main.tsx`
* `src/app/providers.tsx`
* `src/lib/api.ts`

**Goal:** replace `fetch(...)` with `apiFetch(...)`.

**If there is a `defaultQueryFn`:**

```ts
import { apiFetch } from "@/lib/apiFetch";

const defaultQueryFn = async ({ queryKey }: { queryKey: any[] }) => {
  const [url] = queryKey;
  const res = await apiFetch(url);
  if (!res.ok) throw new Error(`Request failed: ${res.status}`);
  return res.json();
};
```

**If queries call `fetch` inside functions (`getReceipts`, etc.):**

* Replace those calls with `apiFetch`.
