This is the smallest upgrade that turns your audit trail from “stored logs” into a **cryptographically verifiable append-only ledger** (GENESIS/LINKED/BROKEN), without changing your operator workflow.

# Audit Trail v1.1 — STRICT SPEC

## Goal

Make `audit_events` **tamper-evident** by:

* assigning a monotonic `seq`
* storing `prevHash` + `hash` per event
* enforcing a single authoritative head
* adding a verification endpoint that recomputes the chain

## Non-goals

* No signatures yet (that’s v1.2+)
* No external anchoring yet (later: publish head hash)

# Data model changes

## 1) Add columns to `audit_events`

* `seq` BIGINT NOT NULL (monotonic, starts at 1)
* `prevHash` TEXT NOT NULL
* `hash` TEXT NOT NULL
* `schemaVersion` TEXT NOT NULL DEFAULT `"audit/1.1"`

### Index / constraints

* `UNIQUE(seq)`
* `UNIQUE(hash)`
* index `seq desc` (for head queries)

## 2) Add a single-row `audit_head` table

Purpose: eliminate concurrency races safely.

Columns:

* `id` INT PK (always 1)
* `lastSeq` BIGINT NOT NULL DEFAULT 0
* `lastHash` TEXT NOT NULL DEFAULT `"GENESIS"`

Ensure a row `{id:1}` exists at startup/migration.

# Hashing rules

## Algorithm

* SHA-256 over UTF-8 bytes of a canonical string.

## Canonical payload (what gets hashed)

Hash input is the stable JSON serialization of this object **with sorted keys**:

* `schemaVersion`
* `seq`
* `ts` (ISO string, UTC)
* `action`
* `actor`
* `receiptId` (or null)
* `exportId` (or null)
* `savedViewId` (or null)
* `payload` (object; stable key order)
* `ip` (or null, if you log it)
* `userAgent` (or null, if you log it)
* `prevHash`

**Rule:** do not include DB `id` in the hash (it’s not deterministic across stores).

## GENESIS rule

* If `lastSeq === 0`, then `prevHash = "GENESIS"` and `seq = 1`.

---

# Append logic (MUST be transactional)

All audit writes go through **one** storage function: `appendAuditEvent()`.

### Transaction steps (Postgres)

1. `SELECT * FROM audit_head WHERE id=1 FOR UPDATE`
2. compute:

   * `seq = lastSeq + 1`
   * `prevHash = lastHash`
   * `ts = now()`
3. `hash = sha256(canonicalStringify({...event, prevHash, seq, ts}))`
4. insert into `audit_events`
5. update `audit_head` set `lastSeq=seq`, `lastHash=hash`
6. commit

This guarantees:

* no duplicate seq
* no split-brain heads
* deterministic chain order

# Verification endpoint

## GET `/api/audit/verify`

Authenticated.

Query params:

* `limit` optional (default 5000, max 50000)

Response:

```json
{
  "status": "EMPTY" | "GENESIS" | "LINKED" | "BROKEN",
  "checked": 1234,
  "head": { "seq": 1234, "hash": "..." },
  "expectedHead": { "seq": 1234, "hash": "..." },
  "break": {
    "seq": 517,
    "reason": "prevHash_mismatch" | "hash_mismatch" | "seq_gap",
    "expectedPrevHash": "...",
    "foundPrevHash": "...",
    "expectedHash": "...",
    "foundHash": "..."
  } | null
}
```

Rules:

* `EMPTY` if 0 events
* `GENESIS` if 1 event and it links to GENESIS
* `LINKED` if all checked events link and the computed head matches `audit_head`
* `BROKEN` on first mismatch/gap

1. **Chain links**

* append 3 events → seq 1..3, hashes linked, head matches

2. **Tamper detection**

* manually update one event’s prevHash → BROKEN prevHash_mismatch
