## Fix 1 — Adapter registry typing (TS2769 + TS7006)

### ✅ Goal

* Stop `new Map([...])` from inferring garbage tuple types
* Eliminate implicit `any` in the mock factory param
* Make the registry strongly typed as `Map<ProviderName, AdapterFactory>`

### Patch (adapter-registry file)

Find the file that defines your adapter registry (often something like `adapter-registry.ts`, `adapters/index.ts`, etc.) and refactor to this shape:

```ts
// BEFORE: usually something like
// export const ADAPTER_REGISTRY = new Map([
//   ["openai", openAIAdapterFactory],
//   ["anthropic", anthropicAdapterFactory],
//   ["mock", (modelId) => makeMockAdapter(modelId)],
// ]);


// AFTER:
import type { ProviderName, AdapterFactory } from "./types"; // adjust path if needed

const entries: Array<[ProviderName, AdapterFactory]> = [
  ["openai", openAIAdapterFactory],
  ["anthropic", anthropicAdapterFactory],

  // If you have a mock adapter factory, type the param explicitly:
  ["mock", (modelId?: string) => makeMockAdapter(modelId)],
];

export const ADAPTER_REGISTRY: Map<ProviderName, AdapterFactory> = new Map(entries);
```

**Important detail:** that `(modelId?: string)` annotation is what kills the implicit `any` (TS7006).
