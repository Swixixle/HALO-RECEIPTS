🔧 NEXT AGENT INSTRUCTIONS — P5 IMPLEMENTATION (RESEARCH DATASET)

Objective

Implement Research Dataset Schema v1.0 and enable safe, anonymized research exports.
No LLMs. No transcripts. No identifiers.

⸻

STEP 1 — Add Research Schema (Canonical)

Create file: shared/research-schema.ts

Define:
	•	ResearchRecordV1
	•	ResearchConsent
	•	ResearchExportEnvelope

Lock version string:

export const RESEARCH_SCHEMA_VERSION = "research-dataset/1.0";

Include:
	•	Explicit exclusions object (hard-coded, always emitted)
	•	Enums for outcomes (verification, signature, chain, platform_category)
	•	Bucketed fields only (no raw counts where avoidable)

⸻

STEP 2 — Database Table

Create table: research_records

Required columns (JSON-safe where appropriate):
	•	research_id (UUID, PK)
	•	dataset_version
	•	capture_date_bucket
	•	verification_date_bucket
	•	platform_category
	•	verification_outcome
	•	signature_outcome
	•	chain_outcome
	•	structural_stats (JSON)
	•	anomaly_indicators (JSON)
	•	risk_categories (JSON)
	•	pii_presence (JSON)
	•	kill_switch_engaged (boolean)
	•	interpretation_bucket (enum or smallint)
	•	consent_scope (JSON)
	•	created_at

❗ DO NOT store:
	•	receipt_id
	•	transcript
	•	hashes
	•	keys
	•	timestamps finer than day

⸻

STEP 3 — Consent Gate

Add explicit consent check before writing any research record.

Consent source:
	•	Receipt-level consent metadata OR
	•	Explicit API parameter (future-safe)

If consent missing or revoked → do not write research record.

⸻

STEP 4 — Research Record Generator

Create pure function:

buildResearchRecord(receipt, verifyResult, forensics): ResearchRecordV1

Rules:
	•	Generate fresh research_id
	•	Bucket all counts
	•	Convert counts → presence flags where specified
	•	Normalize platform → category enum
	•	Never touch raw transcript content

This function must be:
	•	Deterministic
	•	Side-effect free
	•	Testable in isolation

⸻

STEP 5 — Write-once Pipeline Hook

Hook generator after verification completes and before response return.

Flow:
	1.	Verify receipt
	2.	Run forensics
	3.	Check consent
	4.	Build research record
	5.	Persist research record
	6.	Return normal API response (unchanged)

Failure to write research record must NOT affect verification response.

⸻

STEP 6 — Export Endpoint (Private)

Add endpoint:

GET /api/research/export

Requirements:
	•	Auth required
	•	Rate limited
	•	Supports filters:
	•	date range (bucketed)
	•	platform_category
	•	verification_outcome
	•	Returns:

{
  "dataset_version": "research-dataset/1.0",
  "exported_at": "...",
  "record_count": N,
  "exclusions": { ... },
  "records": [ ... ]
}


⸻
