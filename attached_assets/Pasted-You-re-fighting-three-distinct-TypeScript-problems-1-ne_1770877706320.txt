You’re fighting **three** distinct TypeScript problems:

1. `new Map([ ... ])` is being inferred as “array of arrays” instead of “array of 2-tuples” → hence the **TS2769** overload meltdown in `adapters/index.ts`.
2. `modelId` is implicitly `any` in the `mock` factory.
3. In your Express typings, `req.params.*` is `string | string[]`, but your storage APIs want `string`.

Below is the **cleanest deterministic fix** using copy/paste commands (no hand-editing). Run these **from repo root** (`~/HALO-RECEIPTS`).

## 2) Fix `req.params.*` being `string | string[]` (routes)

This does **two things**:

* If you have `const receiptId = req.params.receiptId;` / `exportId = ...`, it converts those declarations to a safe “first element if array” form.
* It also wraps any remaining direct `req.params.receiptId` / `req.params.exportId` usages.

```bash
# 2a) Fix common param declarations
perl -pi -e 's/\b(const|let)\s+(receiptId|exportId)\s*=\s*req\.params\.(receiptId|exportId)\s*;/\1 \2 = Array.isArray(req.params.\3) ? req.params.\3[0] : req.params.\3;/g' server/routes.ts

# 2b) Wrap any remaining direct usages
perl -pi -e 's/req\.params\.exportId/(Array.isArray(req.params.exportId) ? req.params.exportId[0] : req.params.exportId)/g; s/req\.params\.receiptId/(Array.isArray(req.params.receiptId) ? req.params.receiptId[0] : req.params.receiptId)/g' server/routes.ts
```

## 3) Fix `adapters/index.ts` Map typing + `modelId:any`

### 3a) Fix `modelId` implicit any in the mock adapter entry

```bash
perl -pi -e 's/\["mock",\s*\(modelId\)\s*=>/\["mock", (modelId: string) =>/g' server/llm/adapters/index.ts
```

### 3b) Force the Map initializer to be typed as real tuples

This rewrites:

```ts
const adapterRegistry: Map<ProviderName, AdapterFactory> = new Map([
  ...
]);
```

into:

```ts
const adapterRegistryEntries: Array<[ProviderName, AdapterFactory]> = [
  ...
];

const adapterRegistry: Map<ProviderName, AdapterFactory> = new Map(adapterRegistryEntries);
```

…so TS stops treating each entry like a generic `(string | fn)[]`.

```bash
perl -0777 -pi -e 's/const\s+adapterRegistry\s*:\s*Map<ProviderName,\s*AdapterFactory>\s*=\s*new\s+Map\(\[\s*(.*?)\s*\]\);\s*/const adapterRegistryEntries: Array<[ProviderName, AdapterFactory]> = [\n$1\n];\n\nconst adapterRegistry: Map<ProviderName, AdapterFactory> = new Map(adapterRegistryEntries);\n\n/s' server/llm/adapters/index.ts
```
